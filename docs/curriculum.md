# Curriculum
## Module one
Module one covers Python, data structures and AI-assisted coding practice.
## Module two
Module two covers machine learning with scikit-learn, including regression, trees, clustering and model evaluation.
## Module three
Module three covers deep learning with PyTorch, including CNNs and Transformers.
## Module four
Module four covers LLM applications, retrieval-augmented generation, tool use, MCP and LangGraph agents.
